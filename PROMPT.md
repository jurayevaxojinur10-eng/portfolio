# Prompt (AI ga bering)

Menga "Jo'rayeva Hojinur" uchun creative portfolio landing page yarat. U Andijon viloyatidan, bo'lajak dasturchi.

**Texnik talablar**
- Papkalar: `index.html`, `css/style.css`, `js/main.js`, `js/i18n.js`, `images/` (profile.jpg va project1-3 rasmlari). Faqat toza HTML/CSS/JS, framework yo'q.
- Dark / Light rejim tugmasi (tanlov localStorage da saqlansin, tizim rejimini hisobga olsin).
- 3 tilli: UZ / EN / TR. Barcha matnlar `data-i18n` orqali `i18n.js` dagi lug'atdan olinsin, til tanlovi saqlansin.
- Responsive (mobil birinchi), klaviatura fokusi ko'rinsin, `prefers-reduced-motion` hurmat qilinsin.

**Bo'limlar**: Hero (ism, yozilayotgan rollar animatsiyasi, profil rasmi, JS obyekt ko'rinishidagi kod kartasi), Men haqimda (Andijon, maqsad), Ko'nikmalar (progress barlar), Loyihalar (3 ta karta), Aloqa (forma + ijtimoiy tarmoqlar), Footer.

**Creative uslub**
- Palitra: to'q binafsha fon (#120b1e), pushti (#ff7eb6), yalpiz (#7cf5d0), siren (#b69cff); light rejimda krem-pushti fon.
- Shriftlar: Unbounded (sarlavha), Outfit (matn), JetBrains Mono (kod).
- Esda qoladigan element: profil rasmi suyuq (morphing) shaklda, atrofida suzuvchi texnologiya teglari va kod kartasi.
- Sichqoncha ortidan yuruvchi yorug'lik, animatsiyali gradient ism, 3D tilt kartalar, suzuvchi blur dog'lar, scroll orqali paydo bo'lish.
- Rasmlar uchun placeholder qo'y, men keyin o'zimnikiga almashtiraman.
